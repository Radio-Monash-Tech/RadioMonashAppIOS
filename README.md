# Radapp

The iOS app for Radio Monash, independent student radio from the Clayton campus of Monash University.

## Features

- **Live**: stream the station, with on-device live captions, a sleep timer, likes and sharing
- **Schedule**: see what's on and get a reminder before shows you follow
- **Journalism**: reviews, features and opinion from student writers, readable offline
- **Library**: liked songs, saved articles and listening statistics
- Lock Screen Now Playing controls and Home Screen widgets

## Requirements

- Xcode 26
- iOS 18 or later (some features use iOS 26 APIs when available)

## Getting started

```
git clone https://github.com/Radio-Monash-Tech/RadioMonashAppIOS.git
open radapp.xcodeproj
```

Pick the `radapp` scheme and run. There are no third-party packages.
